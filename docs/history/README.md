## 如何使用历史记录

历史章节中的“当前”“下一期”、测试数量、依赖状态和命令均以该章节形成时为准。阅读历史设计时可保留原文；执行安装、迁移、备份或异常处理时应转到当前主题指南。新交付追加独立记录，并链接具体提交与验收，避免覆盖原始测量值。
