# 生产配置检查清单

1. 将 `ENVIRONMENT` 设置为 `production`，关闭 `DATABASE_AUTO_CREATE` 和演示数据。
2. 运行 `python -m app.scripts.manage_migrations upgrade`，确认 `check` 返回最新版本。
3. 配置组织 OIDC issuer、audience、scope 和 JWKS 获取实现，不使用开发 Token。
4. 配置真实 Provider、回调签名密钥、超时、幂等键和补偿人工兜底流程。
5. 使用密钥管理服务注入凭据，日志、诊断和备份不得包含密钥明文。
6. 验证 `/ready`、备份恢复、取消传播、租约接管和副作用 exactly-once 门禁。
